Media storage
-------------
{{- if .Values.objectStorage.enabled }}
  S3 object storage, bucket "{{ .Values.objectStorage.bucketName }}". Pods are stateless and scalable.
{{- else }}
  PVC "{{ include "baserow.fullname" . }}-media" (RWO). Keep backend replicas at 1 unless the
  storage class supports ReadWriteMany.
{{- end }}

Hardening
---------
  All app pods run under the default restricted-v2 SCC: non-root, arbitrary UID,
  read-only root filesystem, dropped capabilities, unprivileged ports (8000/3000).
  No SCC change is required. runAsUser/fsGroup are intentionally NOT set so the SCC
  assigns them from the namespace range.

Branding
--------
  favicon: {{ if .Values.branding.faviconBase64 }}overridden at runtime via ConfigMap.{{ else }}default (set branding.faviconBase64 to override).{{ end }}
  App name, logo and color palette are compiled into the web-frontend image and CANNOT be
  changed at deploy time. To customise them, rebuild this fork's image (see values.yaml
  branding.* comments) and set image.webFrontend.tag / image.backend.tag.
