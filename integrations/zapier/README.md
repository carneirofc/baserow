# zapier

This Zapier integration project was generated by the `zapier init` CLI command.

The Zapier CLI is not a project dependency: its dependency tree carries CVEs the
repo's CVE gate would fail on, and it is only needed to publish. Run it on
demand with `npx` when registering or pushing.

```bash
# Install dependencies
yarn install

# Run tests
yarn test

# Register the integration on Zapier if you haven't
npx zapier-platform-cli register "App Title"

# Or you can link to an existing integration on Zapier
npx zapier-platform-cli link

# Push it to Zapier
npx zapier-platform-cli push
```

Find out more on the latest docs: https://github.com/zapier/zapier-platform/blob/master/packages/cli/README.md.
